# Ebb: menopause symptom tracker (iOS)

Ebb helps women in perimenopause and menopause understand their symptoms: a 30-second daily check-in, an on-device pattern finder, an HRT/treatment before-and-after view, and a one-tap doctor report. Private by design: everything stays on the iPhone.

**New here? Start with [docs/SETUP_GUIDE.md](docs/SETUP_GUIDE.md)** (written for non-coders).

## Features
- **Daily check-in**: 18 symptoms on a None/Mild/Moderate/Severe scale, an optional hot flash counter, lifestyle factors and notes
- **History**: month calendar colored by symptom score, filterable by symptom; tap any day to add or edit
- **Insights**: 30-day score chart, most frequent symptoms, trend detection, trigger patterns (Fisher's exact test, so chance patterns aren't reported), and a weekly summary (Apple on-device AI on iOS 26, template text elsewhere)
- **Treatments**: HRT, non-hormonal medicines and supplements; reminders; dose changes; a before/after "Is it working?" comparison
- **Doctor report**: two-page PDF (symptoms table, weekly chart, patterns, treatments, personalized questions), created on device
- **Learn**: 8 plain-language articles (need clinician review before launch)
- **Privacy**: on-device SwiftData storage, no third-party SDKs, optional Face ID lock, export and delete-all
- **Apple Health** (optional): reads sleep and wrist temperature, writes logged symptoms
- **Subscriptions**: StoreKit 2 + Apple's SubscriptionStoreView, 1-week free trial, $59.99/yr or $9.99/mo

## Tech
- SwiftUI, SwiftData, Swift Charts, StoreKit 2, HealthKit, LocalAuthentication, FoundationModels (optional). iOS 17+.
- `Packages/EbbCore`: pure-Swift logic (pattern engine, report builder, stage estimate) with unit tests: `cd Packages/EbbCore && swift test`
- Project generated by [XcodeGen](https://github.com/yonaskolb/XcodeGen) from `project.yml` (`./setup.sh` does it all)
- CI: `.github/workflows/ios-build.yml` builds the app with Xcode on macOS and runs the tests on every push
